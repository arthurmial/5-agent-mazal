# Content/ — מאמרי גלם

תיקייה זו מכילה מאמרי גלם הממתינים לשכתוב על ידי יעל.

## כיצד להשתמש

שמרו כל מאמר גלם כקובץ טקסט או Markdown בתיקייה זו.
כשתבקשו מיעל לשכתב — היא תחפש כאן.

## פורמטים נתמכים

- `.md` — Markdown
- `.txt` — טקסט רגיל

## תוצרים

לאחר השכתוב, יעל שומרת את הגרסאות המשוכתבות בתיקיית `Output/`.
