# דוגמאות סגנון — yael/reference/

תיקייה זו מכילה דוגמאות לטקסטים בסגנון הכתיבה של הצוות.

יעל קוראת את כל הקבצים בתיקייה זו בתחילת כל משימה ומשתמשת בהם כהשראה ומדריך.

---

## כיצד להוסיף דוגמאות

שמרו כל דוגמה כקובץ Markdown נפרד עם שם תיאורי, למשל:

- `example-blog-post.md` — פוסט בלוג לדוגמה
- `example-linkedin.md` — פוסט LinkedIn לדוגמה
- `example-newsletter.md` — גרסה לניוזלטר לדוגמה

ככל שתוסיפו יותר דוגמאות — כך יעל תכתוב בסגנון מדויק יותר.
