# תמונות השראה — yuval/reference/

תיקייה זו מכילה תמונות השראה לסגנון הוויזואלי של הצוות.

יובל סורק את כל הקבצים בתיקייה זו בתחילת כל משימה ומשתמש בהם כהשראה לסגנון, פלטת צבעים, קומפוזיציה ואלמנטים ויזואליים.

---

## כיצד להוסיף תמונות השראה

שמרו כל תמונה עם שם תיאורי, למשל:

- `brand-colors-example.png` — דוגמה לפלטת הצבעים של המותג
- `style-flat-illustration.jpg` — סגנון איור שטוח
- `photo-style-corporate.jpg` — סגנון צילום עסקי

ככל שתוסיפו יותר תמונות — כך יובל ישמור על עקביות ויזואלית מדויקת יותר.
